# 因子开发提示词

遵循 implement.md，针对 <因子 ID/版本> 先确定经济假设、公式、变量/单位、方向、窗口/最少观测、交易日索引、研究价格口径、可用时点、空值/极值/标准化规则和已知失效条件。

实现必须使用 available_at 不晚于 decision_time 的数据，不把财报期末当公开时间，不用后修订值回填过去，不让未来收益标签进入特征。公式逐语句中文说明，长推导在 docs/factors 与 code_walkthrough 对应真实生产实现。

提供手算固定样本、最少历史/缺失/极端值、同日并列、时点和未来扰动测试；研究统计与交易决策分离。同步配置、版本、Schema、需求映射与文档；不得宣称演示因子必有超额收益。
