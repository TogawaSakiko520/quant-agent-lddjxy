# 故障处理提示词

读取 AGENTS、PROJECT_STATE、相关运行手册和当前持久化事实。先保留 run_id、事件/数据清单、配置、错误和日志；区别数据失效、订单未知、撤单中、对账差异和真实拒单，不盲目重发或清仓。

按 recovery.md 核对订单、成交、持仓、现金和费用；未知状态和未解释差异期间禁止新增风险。撤单、减风险和恢复由独立规则与授权控制。不能删除数据库、覆盖快照、删测试或放宽参数以消除故障表象。

修复前建立能够复现故障的固定测试，最小改动并同步说明，执行恢复/回放验证和独立复核。记录根因、影响范围、实际处置和恢复证据；真实生产操作必须在已有明确授权内。

注释遵循 [根 AGENTS.md 的分层解释规范](../AGENTS.md#按业务语义分层解释qc-014唯一主规范)，重点解释故障后保留的状态、恢复调用前提和不能简化的竞态分支；测试保留反例构造与独立期望。

说明 actual/expected 分别取自哪份账户事实或记录，区分已成交量、委托剩余量与目标缺口；在重要调用和异常出口交代已提交事务是否保留、下一次恢复读取什么。库或语言用法只解释当前故障的业务效果，不用宽泛标题代替局部上下文。
