请先显式读取 AGENTS.md、相关子目录规则、PROJECT_STATE.md、SPEC.md、ARCHITECTURE.md、ASSUMPTIONS.md 和当前任务关联文档，再读取真实 Git 状态及源码。不要依赖聊天记忆，不覆盖他人未提交改动。

目标：<需求 ID 与期望行为>。先陈述现状证据、影响范围、已授权动作和真正的阻塞项，然后执行有边界的小改动。不得因为缺实盘凭证阻止离线工作，不得擅自调用券商或解除实盘阻塞。

交接时更新 PROJECT_STATE：已实现能力、实际运行的完整命令/结果/失败、产物位置、未验证事项、最小下一步。禁止将计划接口写成可运行功能，也不能用“后台继续”代替交付。
