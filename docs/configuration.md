# 演示配置字段与行为

权威定义为 `contracts.DemoConfig`，示例为 `configs/demo.toml`。全部参数仅用于离线工程，**不是投资建议或实盘批准预算**。配置拒绝额外字段、未知版本、联网/实盘模式和非 DEMO 账户；金额用美元 Decimal（十进制），比例用小数表示。

| 字段 | 当前默认值 | 单位与含义 |
|---|---|---|
| schema_version | `1.0.0` | 共同契约版本，不接受未知版本。 |
| mode / demo_only / account_id | `offline` / `true` / `DEMO` | 固定离线演示边界。 |
| seed | `1729` | 合成样本种子；不代表随机市场可重现。 |
| start / end | `2020-09-01` / `2023-12-29` | 合成历史日期，开始必须早于结束。 |
| securities | `30` | 合成普通股数量，范围 2–100；基准另计。 |
| initial_cash | `100000` | 初始模拟现金，美元，必须大于零。 |
| max_positions | `20` | 最多目标持仓数，至少 1。 |
| target_weight | `0.045` | 入选证券基础权重 4.5%，须不大于单票上限。 |
| max_gross | `0.90` | 总持仓价值/净值最多 90%，范围 (0,1]。 |
| max_single | `0.05` | 单票价值/净值最多 5%，范围 (0,1]。 |
| max_sector | `0.25` | 单行业价值/净值最多 25%，范围 (0,1]。 |
| max_turnover | `1.0` | 本次调仓买卖总额/期初净值上限 100%，范围 (0,2]。 |
| max_adv_fraction | `0.01` | 单订单最多占历史 20 日平均成交量 1%，范围 (0,1]。 |
| fee_per_share | `0.005` | 每股美元费用，不得为负。 |
| minimum_fee | `1` | 每笔订单最低美元费用，不得为负。 |
| price_buffer | `0.01` | 买入资金预留 1% 价格变化空间，不得为负。 |
| daily_loss_limit | `0.03` | 演示日内亏损达到约定触发条件后禁止新增风险。 |
| drawdown_limit | `0.10` | 演示高点回撤触发禁止新增风险。 |
| quote_max_age_seconds | `60` | 原始执行报价最大年龄，秒，不得为负。 |
| ranking_buffer | `0` | 首轮明确无排名缓冲，不能改成未实现的新策略。 |
| settlement | `simulated_immediate_settlement` | 合成即时结算，仅限演示；真实账户须读取已确认购买力。 |

默认样本起点提前到 2020-09-01，是为了在 253 个价格观测预热之后仍保留完整的 12/3/3 月研究窗口和末 6 月保留测试；没有缩短因子或研究窗口，也没有降低断言。

候选不足或行业/单票约束限制时留现金，不通过重新归一化突破上限。90% 旧仓全换到另一组证券可能产生 180% gross turnover；100% 上限下允许目标部分完成并说明剩余任务，不能为了完成目标放宽配置。

阈值只能触发处置，不能保证实际损失不超过阈值。报价年龄、费用、缓冲、流动性和换手都需在下单前按实际账户、未完成订单和原始价格重查。异常分支不能通过修改默认值被隐藏。

更改任何字段或默认值时，同步类型/Schema、TOML 示例、本页、相关测试、代码说明、需求映射及 CHANGELOG；风险敏感变更需要独立复核和授权依据。
