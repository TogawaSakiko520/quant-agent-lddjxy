# 隔离的因子研究

研究模块负责描述因子与未来收益之间的样本关系。它不输出交易信号、不训练模型、不优化权重，也不提供生产回测引擎。未来收益标签只存在研究层，不能反向进入因子、评分或订单输入。

## 标签与时间边界

本应用的周频双因子研究先按“稳定证券 ID＋决策时点”筛出动量和低波动均有效的共同样本，完成 253 个价格观测预热后才建立标签和滚动窗口；覆盖率分母仍是所有原始候选，不能因过滤而缩小。纯 `label_observations` 函数可用于隔离单因子研究测试，但应用不能用较早的低波动单因子样本提前启动双因子训练窗口。

每个样本绑定稳定证券 ID、特征决策时点、标签起止时间和冻结因子原值。默认标签从**严格晚于决策的下一可交易开盘**开始，到第 5 个交易日收盘结束；窗口起点先由决策时点和交易日历决定；缺任一窗口行情或尚未到期时跳过，不缩短窗口，也不因首条行情缺失而顺延到更晚开盘。

标签研究可以使用最终修订，但特征必须保留当时快照；研究同样拒绝未封印行情、同版本内容冲突和重复特征，最新标签版本质量不合格时不能回退旧值。研究开盘基值为 `entry.total_return_close × entry.raw_open / entry.raw_close`，标签为末日总回报收盘/该基值减 1；真实执行仍使用独立原始报价。记录标签区间，是为了知道样本何时触及后续阶段信息。

训练/验证/测试分别为 12/3/3 个日历月，每次前移 3 个月；最后 6 个月独立保留。按决策日期分组，同日所有证券同组。若同一天任一样本的标签终点达到或超过本阶段右边界，该日所有样本都清除并留存索引。该规则按实际事件时间生效，不是对行数加一个任意 gap（间隔）。没有完整可用窗口时返回不足，不放松研究边界。

## 当前输出与限制

保存每个因子的覆盖率、逐日 Rank IC（因子名次与后续收益名次的相关性）、平均有效 IC、逐日五分组研究收益和逐日横截面因子秩相关。秩采用平均并列名次；样本不足、常数列或空组保留缺失，不报告虚假的零相关或零收益。分组以因子值和稳定证券 ID 确定顺序。

覆盖率分母来自原始候选数，不得小于有效样本数；重复证券/决策样本会报错。保留全部窗口与实验，禁止只展示最好结果。首轮合成数据只证明该研究流程可运行，不证明因子有超额收益。

这些描述统计不是成本后策略业绩；完整的交易成本、净值曲线、最大回撤、换手、基准与分时期表现需要通过已验收的正式引擎和授权真实数据产生。FakeBroker 工程成交不能填补这项验收。若后续加入预处理、调参或模型，拟合只能读取训练期，验证和最终保留测试权限须明确分开，并记录全部试验预算。
