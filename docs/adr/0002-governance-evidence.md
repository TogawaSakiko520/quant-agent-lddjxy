# ADR-0002：机械检查提供证据，语义与授权由独立复核保证

状态：采用。日期：2026-09-13。

逐语句中文说明通过 AST/tokenize 检查相邻注释与 docstring；它能发现缺失，不能证明注释正确。需求映射检查路径存在，不能证明语义同步。敏感 diff 报告提示测试、风险、CI、规则和依赖变更，不能自动断言测试是否弱化、阈值是否实质放松。

因此维护流程同时要求独立预期样本、独立复核和真实的发布授权。严禁为通过测试删测试、降断言或松风控。开发 AI 不能通过自行修改治理脚本、排除名单或本地批准文件来解除限制。

仓库提供本地检查和 CI 定义，不虚构已配置的远端分支保护、CODEOWNERS 审批人或不可绕过的发布门禁。管理员未来应配置受保护分支、独立审查者和受控生产环境；未完成时实盘仍受 ASSUMPTIONS 的阻塞约束。
