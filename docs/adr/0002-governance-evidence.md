# ADR-0002：机械检查提供证据，语义与授权由独立复核保证

状态：采用。日期：2026-09-13；QC-014 注释规范于 2026-09-19 经用户明确授权修订。

当前注释规范以 [根 AGENTS.md](../../AGENTS.md#按业务语义分层解释qc-014唯一主规范)为唯一来源。AST 检查模块、类、函数真正中文 docstring 和函数类型；取消语句邻接注释及 else/except/finally 独立说明的机械门槛，不引入注释密度、固定行数或关键词计数。普通字符串不能代替 docstring。自动检查只提供说明存在的证据，解释是否正确、业务阶段与边界是否清楚须由语义复核判断。需求映射检查路径存在，不能证明语义同步。敏感 diff 报告提示测试、风险、CI、规则和依赖变更，不能自动断言测试是否弱化、阈值是否实质放松。

2026-09-13 的初始规则曾以 AST/tokenize 检查逐语句相邻中文注释；历史验收记录保留当时口径。本次以独立正反样例迁移该规则，未改变依赖边界、Schema、需求引用及敏感差异等门禁，也未扩大文件排除范围。迁移对应和实际验证见 [QC-014 记录](../audit/comment-semantics-migration.md)。

因此维护流程同时要求独立预期样本、独立复核和真实的发布授权。严禁为通过测试删测试、降断言或松风控。开发 AI 不能通过自行修改治理脚本、排除名单或本地批准文件来解除限制。

仓库提供本地检查和 CI 定义，不虚构已配置的远端分支保护、CODEOWNERS 审批人或不可绕过的发布门禁。管理员未来应配置受保护分支、独立审查者和受控生产环境；未完成时实盘仍受 ASSUMPTIONS 的阻塞约束。
