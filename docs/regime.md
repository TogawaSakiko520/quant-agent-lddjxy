# 市场状态观察器

`Regime` 指市场状态及其切换。版本为 `observer-1.0.0`，首轮 `affects_budget=false`，只观察并记录依据，不改变目标仓位或因子权重。

调用方显式选择单一基准并传入 `TradingCalendar` 与 UTC `as_of`。历史版本按可用时点过滤并核验来源哈希、同版本冲突及质量；从起始记录到最近已收盘交易日必须具有完整日历序列。缺日历、缺历史、缺日、过期或质量不合格时输出明确 `UNKNOWN` 原因，不能把压缩后的观测当连续交易日。

完整历史至少 200 个交易日，之后逐日只用当前及此前价格计算状态。价格/SMA200（200 日简单平均）大于 1.01 提议 UP，小于 0.99 提议 DOWN，中间保持既有状态；新方向需连续 3 个交易日确认。起始趋势是 NEUTRAL。

最近 61 个总回报价格形成 60 个简单日收益，用样本标准差乘 `sqrt(252)` 年化。普通波动状态下大于 25% 提议进入 HIGH_VOL；高波动状态下低于 20% 提议退出，中间保持状态；切换同样需要连续 3 日。输出为趋势与波动的组合标签，并保留价格比值、年化波动、待确认次数和 `observation_only`。

上述阈值、窗口和确认规则都是透明演示规则，不是最优参数或实盘风控预算。UNKNOWN 不会在本轮隐式改变仓位，交易是否可继续仍由独立数据质量与风控判断。更改规则需升级版本，更新未来扰动、迟到、缺日、阈值/确认测试及本文；将来状态影响预算需要单独验证与批准。
