# 周频双因子策略

策略版本：`weekly-two-factor-1.0.0`。职责是形成信号和约束后目标，不能调用券商。使用普通股历史股票池，日频观察，在每周最后交易日收盘且数据完成校验后决策，在下一合格常规时段执行。演示参数均未获得实盘批准。

## 输入与评分

数据先按 `available_at <= decision_time` 选择修订并验证哈希、质量和历史证券身份。只使用同一快照、同一决策时点、`momentum`/`low_volatility` 的 `1.0.0` 版本；未知因子、重复结果或跨快照输入显式报错。

两个因子都有效的证券组成共同横截面，缺任一因子则剔除并记录原因，不填零、不沿用旧值。样本少于 2 返回空信号。每个因子值升序排列，完全相同值采用零基平均名次，除以 `N-1` 得到 [0,1] 百分位；没有额外浮点近似并列规则。两个百分位各占 50%；最终得分降序、稳定证券 ID 升序。排名只表示同日相对位置，不是收益预测。

`decision_id` 由快照与固定策略版本确定，不依赖运行目录或随机 run_id；重新运行同一决策不得生成新的交易身份。排名缓冲首轮为 0，不动态优化因子权重。

## 组合与订单的职责分离

默认最多 20 只、每只基础目标 4.5%，总仓位 90%、单票 5%、行业 25%。先保留无法交易的旧仓并占用对应预算；候选缺报价或不可交易时说明原因。额度与原始价格按整股向下取整，合格数量不足或约束不可行时留现金，不能重新归一化突破上限。

目标组合只使用决策时已知的原始报价、账户和主表，不能提前读取下一开盘或执行时才刷新的账户事实。订单规划再读取执行时原始报价、实际账户和未完成订单，扣除已有数量与预留额、费用、价格缓冲、ADV（平均每日成交量）和换手预算。未成交卖单收入不可用作现有现金。已有本决策成交时，从唯一成交事件累计真实 `price × quantity` 作为换手，不能用卖单最低限价估计；活动订单按当前价与限价的较大值预留。所有旧仓、挂买单和本轮计划买单共同占用限价风险额度和名额，手续费降低可用净值，卖单实际成交前不释放这些额度。同一证券已有活动订单时等待其完成，不再建立可能冲突的新单。

“目标持仓”“计划意图”“已提交委托”“实际成交”分别保存。目标未完全实现不是自动放松约束的理由。所有操作最终经过 execution 唯一入口和按操作种类定义的风险/授权检查；正常新增必须提供同一决策的批准目标、正的期初净值和高点净值，缺失不能跳过亏损或回撤规则。提交前还要核对当前主表资格、有效区间、可用时点，以及报价字典键与 Quote.security_id 一致。未知订单先恢复对账。

## 版本变更与验证

更改公式、评分、样本资格、并列、缓冲、调仓时点或约束会改变策略行为：先建立固定边界测试，再同步相关因子/策略版本、配置、Schema、中文说明、需求映射和本页。测试包含手算、缺样本、并列、未来数据扰动、不可行组合、挂单预留及下一时段执行。

研究验证与 FakeBroker 工程演示分开。真实回测、成本模型、模拟/影子表现和有限实盘需要分别验收；本策略不保证盈利。
