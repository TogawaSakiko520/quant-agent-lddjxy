# 故障、恢复、迁移与回滚

## 数据或运行失败

保留 run_id、决策时点、配置、数据哈希、错误和日志。质量不合格时停止正常新增风险，定位缺失/过期/重复/单位/异常价格或公司行动问题。修订产生新版本和新输出目录；不得覆盖旧快照后冒称原运行可复现。

## 订单未知或断线

禁止盲目重发；发送超时不等于拒单。使用持久化意图、幂等键和券商订单 ID 核对未完成订单、成交、持仓、现金、费用与人工交易。重复和乱序事件经唯一事件标识处理。撤单请求不是撤单成功；撤单中发生的成交仍必须入账。

对账差异未解释或关键状态未知时禁止新增风险。取消未完成订单与减仓是独立受控操作，不能用一个总开关或盲目清仓代替诊断。离线 FakeBroker 故障测试不代表真实券商恢复已验收。

## 事件顺序与公司行动

内部 journal（按写入顺序保存的操作日志）保留 intent、order、event、action 的真实交错顺序；公司行动不能在回放时统一移到成交之前或之后。同一成交的不同 event_id 投递封装仍留痕，但按来源与成交 ID 只产生一次账务影响。行动必须通过哈希与质量校验，并以显式 UTC 处理时点确认其 event_time 和 available_at 均不晚于当时；未来行动不能提前改变现金或持仓。

账户执行锁位于固定的 `/tmp/quant-core-account-locks/<账户哈希>.lock`，不会因运行目录、数据库或用户 ID 不同而分裂；锁竞争或权限失败即停止。人工交易及身份冲突留下永久冻结，不提供自动解除接口；普通尚缺公司行动/现金事实的对账差异在证据齐全后可以恢复。

## 备份与恢复演练

停止或隔离唯一写入者；使用存储支持的一致性备份机制备份事件库，连同快照清单、配置和依赖锁保存。本轮 SQLite 采用短连接与 rollback journal（回滚日志），无待合并 WAL；如果未来改变存储模式，不要在 WAL 活跃时只复制主数据库文件。校验备份哈希，在新目录恢复，重放并比较事件数量、账户/订单终态和报告追踪信息。保留演练执行者、时间、命令和差异。

## 迁移与回滚

当前不存在已批准生产迁移。以后每次 Schema/状态库变更先备份，在复制环境执行兼容检查和回放；明确旧版本能否读取新事件，禁止把未知枚举默认为正常状态。回滚应用版本前验证数据兼容；必要时恢复已验证备份并核对恢复点之后的外部成交，不能直接丢弃交易事实。

真实运行的关键告警须独立于日报通知，有处置人、确认、恢复步骤和演练证据。当前未配置真实通知渠道与值守人，不能宣称生产监控已经完成。

## 单次 Alpaca Paper 的恢复边界

Paper使用同一计划目录的internal.sqlite和已批准的固定预算。适配器读取初态之后订单以及全账户开放订单，初态之前终态订单只保存历史证据；所有未知开放/新增订单阻断，不自动撤销。逐笔FILL经原账务去重，不从订单累计量与均价反推成交。

网络读取期间可以产生合法新成交，因此ExecutionService在完整事件响应后刷新注入时钟才判断未来事件，账户响应后再记录最终核对时刻；真正未来事件仍冻结。API各次读取并非原子快照，临时订单/成交不一致须再恢复，不能抹掉差异。

本阶段每个决策/证券/方向仅一张意图，部分成交后取消也不能同计划重开余量。未知发送先查询，不重发。新增非FILL资金/公司行动、碎股或账户差异明确停止。初态JNLC等已包含现金的活动按完整内容摘要固定，不重复记账；不能把新活动当旧活动跳过。命令、价格步长与追加观察记录见[Paper手册](alpaca-paper.md)。

## 已知旧版预提交失败的维护


正常新版本在POST之前的账户/时间/请求校验失败抛出明确的未发送异常，追加本地REJECTED；调用POST后的超时或坏回执仍保留待恢复。排队测试若券商时钟领先本机不超过1秒，会实际等待本机追上后再作原有严格校验，保存queue-clock-checks.json，不重写时钟或旧报价。

2026-09-20记录的一次旧版排队尝试在POST前失败，但旧服务保守记为UNKNOWN。仅此固定源码指纹和原因可使用 `paper-recover --confirm-unsent-source <旧源码目录>`，其余恢复参数保持1笔/500美元/cancel。应用先核实完整旧代码树、原计划和原始失败证据，保存unsent-proof.json；执行服务持锁确认唯一意图、无券商ID/成交、仅该单未确认差异及再次查询无远端订单后，追加本地REJECTED并再次核对。它不改现金、删除历史、解冻或重发。目录缺失、证据不符、其他差异或远端已出现订单时停止；普通404绝不授权使用此维护。详细原始版本及审查依据见[本轮审计](../audit/paper-queue.md)。
