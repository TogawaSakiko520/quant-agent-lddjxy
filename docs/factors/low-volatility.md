# 低波动因子

稳定 ID：`low_volatility`；版本：`1.0.0`；单位：`annualized_ratio`。

经济假设：较低的历史波动可描述更平稳的价格路径，但不代表低估值、不会下跌或保证高收益。跳空、制度变化和相关性上升都可能使历史波动失去代表性。

由 61 个连续有效总回报价格得到最近 60 个日收益 `r_i = P_i / P_(i-1) - 1`。计算样本标准差 `sqrt(sum((r_i-r_mean)^2) / (60-1))`，乘 `sqrt(252)` 年化，最后取负。年化以一年 252 个交易日为演示约定；`ddof=1`，不是总体标准差。输出为无量纲，数值越大意味着波动越低。

手算边界：61 个价格全为 100 时，60 个收益均为 0，因子为 0；只有 60 个价格时必须判定历史不足。含缺失、非有限或非正价格不能直接计算正常因子。首轮不对有效极端值缩尾或裁剪；非有限/非正价格拒绝，缺日不压缩窗口、不插值。不得因结果难看临时改变。

同日合格横截面统一方向评分，与动量固定等权。窗口、年化约定、空值或价格口径变化需同步更新公式测试、配置说明、代码注释与因子版本。
