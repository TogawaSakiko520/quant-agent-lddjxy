# 动量因子

稳定 ID：`momentum`；版本：`1.0.0`；单位：`ratio`。

稳定经济含义：过去一段时间的相对强弱可能持续，也可能在反转和拥挤交易中失效。这里只定义可复现演示，不宣称超额收益。

公式为 `P[t-21] / P[t-252] - 1`。`P` 是截至决策时点可知的总回报研究价格，t 是最新合格交易日索引；索引单位是交易日，不是自然日。需要至少 253 个连续有效价格观测，跳过最近 21 个交易日；计算方向为越大越好，结果是无量纲收益比。

手算固定样本：若 `P[t-252]=100`、`P[t-21]=120`，动量为 `0.20`；改变 `P[t]` 不应改变该窗口公式，但改变可用性或质量可能使证券失去资格。价格须为正且有限，窗口缺失或数据时点不合法不能静默补成正常值。

同日仅保留两个因子均有效的共同股票池；任一因子缺失则剔除该证券并记录原因，不填零或沿用前值。共同样本少于 2 时返回空信号。单因子按值升序，以零基平均并列名次除以 N-1 映射至 [0,1]；完全相同值才算并列，不额外引入浮点近似并列。两个百分位各占 50%，最终按得分降序、稳定证券 ID 升序排序。排名缓冲为 0。每次公式/窗口/价格口径变化必须升级因子版本并更新本页及手算样本。
